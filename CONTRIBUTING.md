# Contributing to Hark

Hark is built by people who learn, experiment, and share.

Nobody writes perfect code. If you see something that can be better, help make it better.

## How to contribute

1. Fork the repository.
2. Make your changes.
3. Test them.
4. **Please push your changes to the `dev` branch, not directly to `main`.**
5. Open a pull request explaining what you improved.

Found a bug? Have an idea? Better documentation? All contributions are welcome.

## A few principles

- **Keep it simple.** Prefer clear solutions over clever ones.
- **Stay curious.** Ask questions. Learn from feedback.
- **Make it better.** Small improvements matter.
- **Be respectful.** Everyone starts somewhere.
- **Protect sensitive data.** Never commit real tokens, cookies, credentials, or private captures.
- **Test responsibly.** Only test systems you own or have permission to assess.

You don't need to be an expert. You just need to be willing to cbro ontribute.

**Build. Learn. Share. Repeat.**

Thanks for helping make Hark better. 💚
